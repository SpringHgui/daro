## 测量方法（可复现）

- 显示器 3840×2160 @200%，截图与坐标都是**物理像素**，逻辑像素 = 物理 / 2。
- 探针脚本在 `.scratch/navicat/nv.py`：
  - `capture(hwnd, path)`：PrintWindow，抓客户区；
  - `real_click/real_move/send_text`：SendInput 真输入（**PostMessage 的鼠标消息 Qt 会丢**）；
  - `foreground(hwnd)`：AttachThreadInput 绕过前台锁（否则点击落到别的窗口上）；
  - `popup_menu(hwnd)` + `dump_menu_hmenu`：右键菜单是原生 `#32768` 窗口，
    用 `MN_GETHMENU`（0x1E1）取 HMENU 后逐项读状态。菜单文字是 owner-draw，
    `GetMenuItemInfo` 拿不到文本，只能截图看字（结构/灰态能读）。
- 坑：Navicat 主窗 `TNavicatMainForm` 的截图包含原生标题栏（58 物理像素），
  而 `ClientToScreen` 的客户区原点在标题栏之下 —— 点树行时 `client_y = 截图 y - 58`，
  否则会稳定点错一行。

## 图标重绘（2026-10-31）

参考工具那批图标是**多色 + 立体感**的（蓝表 / 红窗 / 绿加号 / 铜色 Ent 角标），
原来的 daro-rs 用的是 lucide 单色线稿，这是「界面还原度」最扎眼的一处。

### 为什么没用位图 / SVG

- GPUI 的 `svg()` 走 `svg_renderer::render_alpha_mask`：SVG 先被光栅化成**单色 alpha 蒙版**，
  再用一个 `text_color` 上色。彩色 SVG 进去，出来只剩一种颜色 —— 那批图标恰恰是多色的。
- 位图在右侧信息卡的 60+ px 大图上会糊，且明暗主题 / 任意 DPI 都要额外维护多份。

### 做法

新增 `src/art.rs`：用 `canvas` + 四边形 / 多边形 / 折线 / 三次贝塞尔自己画，
坐标统一落在 **24×24 设计格**里，绘制时按目标尺寸整体缩放。于是同一份图标
既能喂 15～16px 的树行与对象列表，也能喂 62px 的信息卡大图，任意 DPI 都清晰。

| 位置 | 图标 |
|---|---|
| 功能区 13 项 | 插头 + 绿加号 / 红蓝双窗 / 蓝表 / 表 + 眼镜 / 红表 + 眼镜 / f(x) / 黄衣人像 / 工具托盘 / 红蓝双窗 / 灰块 + 循环箭头 / 青绿机器人 / 橙色立方体 / 紫色柱图 |
| 功能区角标 | 备份 / 自动运行 / 模型 / BI 右下压橙色 `Ent` 角标（与参考一致） |
| 左树 | 分组黄文件夹、连接按引擎品牌色（MySQL 蓝 / PG 深蓝 / SQL Server 红 / Mongo 绿 / Redis 红）、库与模式（三绿块拓扑图）、表 / 视图 / 实体化视图 / 函数 / 查询、字段 |
| 对象面板 | 表行与卡片：深蓝表头 + 2×2 棋盘表身（取样 `#0a7cd4` / `#cee8ff` / `#94cff9` / `#adddff` / `#7cc3f9`） |
| 工具条 | 打开表 / 设计表 / 新建表 / 通过 AI 新建表 / 删除表 / 导入 / 导出 |
| 右侧信息卡 | 62px 大图标：表卡片、蓝色库圆柱、绿色模式拓扑图（深绿表头 `#0b7a3f` + 体 `#3ec488` + 线 `#5d6f80`），与参考同一套取样色 |

单色线稿仍可通过 `art::Glyph::Lucide(IconName)` 使用；`From<IconName>` 会把
常用几款（Table2 / Eye / Layers / SquareFunction / SquareTerminal / Database /
Folder* / Boxes）自动映射到重绘版，所以老的调用点不必逐个改。

### 浮层列选择面板（2026-10-31 第二轮）

参考工具在「字段 / 被引用的字段」格右侧有一个 `…`，点开是浮层：**勾选列 + 上移/下移/
删除 + 确定/取消**（外键、唯一键、索引都用这一套）。这一轮把这个形态做出来了：

| 部件 | 实现 |
|---|---|
| 数据 | `DesignPopup { target, row, items: Vec<(列名, 勾选)>, sel }`，挂在 `DesignerState.popup` |
| 打开 | 索引 / 外键（本地字段、被引用字段）行尾各加一个 `…` 按钮 → `design_open_picker()`：候选 = 表里所有列 + 字段串里已有但不在列里的项（自由文本、引用表的列不会被吞），**已勾选的排在最前** |
| 交互 | 点行 = 勾选/取消；`↑ ↓` 挪动选中行（顺序即写回顺序）；`−` 取消勾选；`确定` 按列表顺序拼成 `a, b, c` 写回模型；`取消` 不动模型 |
| 外观 | 白底 + 1px 边框 + 阴影，表头浅灰；索引面板带参考图那 6 列（排序规则模式 / 排序规则 / 运算符类别模式 / 运算符类别 / 排序顺序 / Nulls 排序）的**只读展示值**（`pg_catalog` / `default` / `ASC` / `NULLS LAST`） |
| 守护 | `design_picker_commits_columns_in_order`：勾选顺序写回、再开时已选在前、取消不改模型 |

> 注意：这轮没有启动 GUI 截图（用户要求别弹窗打断），只做了 `cargo build` +
> `cargo test -- --test-threads=1`（61 项全绿），视觉项按上面的度量改的。
