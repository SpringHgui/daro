# daro-rs 交互细节台账

对照基准：本机 **Navicat Premium Lite 18**（`C:\Program Files\Navicat\Navicat Premium Lite 18\navicat.exe`）。
本文件记的是「实测到什么数 / 差在哪 / 改了没有」，和 [FEATURES.md](FEATURES.md) 的
功能清单分工不同：FEATURES 记「入口能不能点通」，这里记「点下去像不像」。

## 测量方法（可复现）

- 显示器 3840×2160 @200%，截图与坐标都是**物理像素**，逻辑像素 = 物理 / 2。
- 探针脚本在 `.scratch/navicat/nv.py`：
  - `capture(hwnd, path)`：PrintWindow，抓客户区；
  - `real_click/real_move/send_text`：SendInput 真输入（**PostMessage 的鼠标消息 Qt 会丢**）；
  - `foreground(hwnd)`：AttachThreadInput 绕过前台锁（否则点击落到别的窗口上）；
  - `popup_menu(hwnd)` + `dump_menu_hmenu`：右键菜单是原生 `#32768` 窗口，
    用 `MN_GETHMENU`（0x1E1）取 HMENU 后逐项读状态。菜单文字是 owner-draw，
    `GetMenuItemInfo` 拿不到文本，只能截图看字（结构/灰态能读）。
- 坑：Navicat 主窗 `TNavicatMainForm` 的截图包含原生标题栏（58 物理像素），
  而 `ClientToScreen` 的客户区原点在标题栏之下 —— 点树行时 `client_y = 截图 y - 58`，
  否则会稳定点错一行。
